# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith,
keep criticism about the work and not the person, and do not harass anyone. Maintainers may remove comments, commits and contributors that break these rules.

Report a problem privately through GitHub (contact a maintainer, or use a private security advisory if it involves safety). We will treat the report as confidential.
