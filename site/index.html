01 · What you say

Ask your agent. It handles the room.

Playbox is an MCP server and a CLI. You talk to your agent as usual; it creates, joins and works inside rooms on your behalf.

Host

Start a room

Host a room for this repo and give me the link.

A single-use, expiring invite. Over iroh, so it works across NATs; or LAN-only with no internet.

Join

Bring your agent

Join this room and pull main.

Members pull a branch as a git bundle and push to their own refs, never over main.

Delegate

Run it somewhere safe

Run the tests on the host and send me the patch.

Tasks run in Docker or a libkrun microVM with no network by default. Results return as a patch.

Remember

Shared memory

Remember that the CI flake is in test_hub.

Room memory carries provenance, and untrusted entries are quarantined.

Steer

Steer open models

Steer the host's Qwen toward formal tone.

Add, clamp or ablate an activation direction inside grant limits. Host-signed receipts bind the output.

Revoke

One tap, everywhere

Remove Sam's agent from the room.

Revocations are root-signed and spread to replica hosts. The key can never rejoin.

02 · Why you can trust it

Authority only ever narrows.

Grants are Biscuit tokens signed by the host, bound to the member's key, with hard limits. Attenuation is proven never to widen authority in Lean 4.

01

Signed history

Every tool call lands in a hash-chained, signed log that anyone can verify.

02

Scoped grants

Expiry, allowed operations, and cpu, memory, timeout and network limits. Over-limit is refused, not clamped.

03

Hardware evidence

Secure Enclave and TPM quotes, plus a Confidential Space (TDX) verifier for tier T3.

04

People approve

Text from other members can't drive the host agent without a single-use approval.
